# Город Н

Проект превращает свежие новости Сызрани в весёлые посты для соцсетей в стиле Остапа Бендера.

> «В городе Н сегодня произошло преинтереснейшее событие…»

## Идея

1. Взять последние новости с городских сайтов **маленькая Сызрань** ([syzran-small.ru](https://www.syzran-small.ru), приоритет) и **КТВ-ЛУЧ** ([ktv-ray.ru](https://ktv-ray.ru)).
2. Выбрать одну-две **позитивные, забавные, необычные** новости. Криминал, ДТП, смерти, катастрофы, болезни и политику не берём: над этим не шутим.
3. Пересказать новость на 4–5 предложений голосом Остапа Бендера: ирония, «великий комбинатор», цитаты из «12 стульев» и «Золотого телёнка», но **без искажения фактов**.
4. Собрать пост: цепляющий заголовок, зачин «В городе Н сегодня произошло преинтереснейшее событие:», пересказ, ссылка на источник.
5. Написать промт и сгенерировать иллюстрацию (Cloudflare FLUX.1 schnell).
6. Опубликовать в соцсетях (Telegram, VK, MAX, Instagram — через Postmypost: MCP или REST API, `scripts/pmp_api.py`) и записать результат в JSON поста.

Посты выходят три раза в день, около 8, 14 и 20 часов: cron на VPS запускает Claude Code, тот выбирает новость, пишет пост, рисует картинку, отдаёт пост на фактчек и публикует.

## Источники новостей

Два источника, вес при отборе **2 : 1 в пользу «маленькой Сызрани»**: при сравнимых новостях берём её, а если одно событие есть на обоих сайтах — источником поста ставим «маленькую Сызрань».

### маленькая Сызрань (приоритетный)

| Что | Адрес | Примечание |
|---|---|---|
| RSS для Яндекса | `https://www.syzran-small.ru/rss-ya.php` | основной способ: ~28 новостей с полным текстом (`yandex:full-text`), картинка, дата (+03:00). Кодировка windows-1251 |
| Статьи | `https://www.syzran-small.ru/pages-<id>` | тоже попадают в RSS — **не берём** |
| Страница новости | `https://www.syzran-small.ru/news-<id>` | для старых новостей, которых уже нет в RSS |
| Обычный RSS | `https://www.syzran-small.ru/rss.php` | всего 5 новостей, не используется |

### КТВ-ЛУЧ

| Что | Адрес | Примечание |
|---|---|---|
| RSS-лента | `https://ktv-ray.ru/feed.rss` | 20 последних новостей, есть полный текст (`yandex:full-text`), дата, картинка (`enclosure`) |
| Лента на сайте | `https://ktv-ray.ru/novosti/` | ~29 новостей на странице, включая «главные» более старые |
| Страница новости | `https://ktv-ray.ru/novost/<slug>/<id>/` | `id` — числовой, растёт со временем |
| Короткая ссылка | `https://ktv-ray.ru/n/<id>/` | перенаправляет на страницу новости; её и ставим в пост (`/novost/<id>/` без хвоста — 404) |

Кодировка UTF-8. Основной способ получения новостей: RSS. При нехватке материала добирать со страницы `/novosti/`.

Обе ленты скачивает `python scripts/fetch_news.py` (общий список с метками `МС` / `КТВ`), полный текст — `--show <ID>`.

## Критерии отбора новости

- **Подходит:** местные события Сызрани и области, курьёзы, благоустройство, достижения горожан, необычные находки и продажи, праздники, животные, природа.
- **Не подходит:** насилие, гибель людей, ДТП, мошенничество с пострадавшими, военные события, медицина «про болячки», политика, гороскопы и приметы (это уже готовый юмор, его не перешутить).
- Плюс, если в новости есть цифры, деньги, бюрократия или абсурд: Бендеру есть где развернуться.

## Формат поста

Каждый пост — один JSON-файл в папке `posts/`, картинка лежит рядом с тем же именем:

```
posts/20261006_1855-scorpions.json
posts/20261006_1855-scorpions.jpg
```

Имя: `YYYYMMDD_HHMM-name`, где дата и время — момент публикации (плановый или фактический, местное время), `name` — короткое латинское слово о сюжете.

```json
{
  "id": "20261006_1855-scorpions",
  "created": "2026-10-06T16:50:00+04:00",
  "source": {
    "name": "КТВ-ЛУЧ",
    "url": "https://ktv-ray.ru/novost/.../195344/",
    "news_id": 195344,
    "title": "Заголовок новости в первоисточнике"
  },
  "title": "Ветер перемен подул в сторону «Авито» 🎸",
  "body": "В городе Н сегодня произошло преинтереснейшее событие: …",
  "hashtags": ["#городН", "#Сызрань", "#ОстапБендер", "#Scorpions"],
  "image": {
    "file": "20261006_1855-scorpions.jpg",
    "prompt": "Vintage Soviet book illustration …",
    "model": "@cf/black-forest-labs/flux-1-schnell",
    "steps": 8,
    "url": "https://files.catbox.moe/ox86v7.jpg"
  },
  "publications": [
    {
      "platform": "vk",
      "channel": "В городе Н сегодня произошло",
      "status": "published",
      "published_at": "2026-10-11T21:45:00+04:00",
      "via": "postmypost",
      "project_id": 365896,
      "account_id": 2334893,
      "post_id": "32712035",
      "file_id": "53858370",
      "url": "https://vk.ru/wall-242062669_29",
      "error": null
    }
  ]
}
```

| Поле | Что это |
|---|---|
| `source` | первоисточник: издание, ссылка, ID и заголовок новости |
| `title`, `body`, `hashtags` | заголовок, пересказ (4–5 предложений), хэштеги |
| `image.prompt` | промт иллюстрации (на английском); `model`, `steps`, `seed` — чем сгенерирована |
| `image.file` | имя картинки рядом с JSON |
| `image.url` | публичная ссылка на картинку (nginx на VPS или catbox.moe), по ней Postmypost её забирает; пусто, пока не загружена |
| `publications` | по записи на каждую площадку; `status`: `published` / `scheduled` / `error`. Записи `via: "postiz"` — старые (Postiz отключён 12.10) |

Пост не опубликован на площадке, пока в `publications` нет записи с её `platform` и `status: "published"`.

Текст для соцсетей собирается из полей: заголовок, пустая строка, пересказ, строка со ссылкой на источник («Узнал здесь: <ссылка>», «Говорят там: <ссылка>»… — вариант выбирается по `id` поста), хэштеги (у своей новости из бота ссылки нет — и строки нет). В Telegram подпись к фото ограничена 1024 символами. Проверить: `python scripts/post_json.py posts/<пост>.json`.

## Бот для своих новостей

Кроме новостей с сайтов, можно прислать свою: боту в Telegram или в MAX («ГородН - редакция»). Бот отвечает только владельцу, сообщения остальных пользователей игнорирует.

1. Отправить боту текст новости одним сообщением, можно с фото или альбомом.
2. Через пару минут бот присылает готовый пост с картинкой и кнопками: **Сейчас**, **В очередь** (выйдет со следующим автопостом), **Ко времени**, **Переделать**, **Отмена**. Без нажатия кнопки ничего не публикуется.
3. Картинка:
   - есть фото — в пост идёт оно, тонированное в сепию;
   - в тексте есть слово «карандаш» или «акварель» — вместо сепии будет рисунок по фото в стиле старой книжной иллюстрации;
   - фото нет — картинку рисует нейросеть, пожелание к ней можно дописать строкой «Картинка: …».
4. Слова «от лица Бендера» в тексте — пост будет от первого лица: Остап сам видел и рассказывает.

Команда `/status` показывает прошлый пост и где он вышел, что сейчас в работе и в очереди и когда следующий автопрогон (скриншот выше).

Бот — `scripts/inbox_bot.py`, работает на VPS, cron перезапускает его, если он упал (`auto/inbox_bot.sh`). Пост по присланной новости пишет Claude Code по тому же скиллу (раздел «Своя новость (бот)»).

## Структура проекта

```
gorod-n/
├── README.md            — описание проекта (этот файл)
├── .claude/skills/city-n-news-to-soc/ — скилл Claude Code: весь цикл от новости до публикации
├── .env.example         — какие ключи нужны и где их задать (переменные окружения)
├── prompts/
│   └── bender_style.md  — инструкция по стилю пересказа и отбору новостей
├── data/
│   ├── raw/             — снимки ленты новостей (RSS, список заголовков) по датам
│   └── selected/        — выбранные новости: исходный текст + почему выбрана
├── posts/               — посты: YYYYMMDD_HHMM-name.json + картинка .jpg с тем же именем
├── gitimg/              — скриншоты для README
└── scripts/
    ├── fetch_news.py    — ленты «маленькой Сызрани» и КТВ-ЛУЧ: скачать, список, полный текст по ID
    ├── post_json.py     — пост: текст/HTML, запись публикации, переименование по времени
    ├── gen_image.py     — картинка по image.prompt из JSON
    ├── gen_cover.py     — обложка группы VK
    ├── photo_sketch.py  — фото пользователя → карандашный рисунок
    ├── recolor_to_sky.py, sepia_tone.py — тонирование картинок
    ├── pmp_api.py       — публикация через REST API Postmypost (если MCP недоступен)
    └── inbox_bot.py     — бот для своих новостей (Telegram / MAX)
```
