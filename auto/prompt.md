Автономный запуск автопостинга «Город Н» (cron на VPS, пользователя рядом нет).

Используй скилл city-n-news-to-soc и работай по его разделу «Автономный режим»:
закрой хвосты прошлых запусков (шаг 0), проверь очередь своих новостей
(`python scripts/inbox_bot.py queue` — если есть, публикуешь её вместо новости с сайта), иначе скачай свежие новости, выбери одну,
напиши пост, сгенерируй и проверь картинку и сразу опубликуй через Postmypost
в Telegram + VK + MAX + Instagram (если MCP Postmypost не подключается — через
`python scripts/pmp_api.py publish`, см. скилл, раздел 7). Вопросов не задавай. Если подходящей новости нет —
ничего не публикуй и запиши причину.

В конце — итог в 3–5 строк: заголовок, источник, файл поста, ссылка VK
(или причина пропуска / ошибки).
