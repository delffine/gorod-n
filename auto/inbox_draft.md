Своя новость «Город Н» из бота: элемент data/inbox/{ITEM}/. Пользователя рядом нет,
отвечает он только кнопками в боте — вопросов не задавай.

Используй скилл city-n-news-to-soc, раздел «Своя новость (бот)», режим «Черновик»:
по data/inbox/{ITEM}/text.md (и замечаниям feedback из meta.json, если они есть)
напиши или переделай пост, сделай картинку, прогони фактчек. Ничего не публикуй.

В конце обязательно запиши статус командой из скилла:
python scripts/inbox_bot.py set {ITEM} status=draft post=<путь к JSON поста> "factcheck=<вердикт одной строкой>"
а если пост сделать нельзя — status=error и "error=<причина для пользователя>".

Итог — 2–3 строки: заголовок, файл поста, вердикт фактчека (или причина ошибки).
